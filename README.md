# Calorie Counter

A simple calorie tracking app built with HTML, CSS, and JavaScript.

## Features

- Add food items with calorie values
- Remove items from the list
- See the total calories for the day
- Reset the daily calorie intake
- Persist data using localStorage
- Use a simulated Fetch API example

## Run locally

Open `index.html` directly in a browser, or serve the folder with a local web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
